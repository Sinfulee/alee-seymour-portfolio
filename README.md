# A Lee Seymour: AI Operations and Prompt Design Portfolio

I build working AI systems by directing AI through prompts, with no formal coding training. This portfolio is a read-only record of that work: what I built, how it changed over time, how I checked its quality, and where the public results live. It links only to content that is already public.

## How it is organized

The portfolio is built in layers:

1. **This page:** who I am, the map, and how to read the labels.
2. **One folder per body of work.** Each has a `README.md` index with labels for every entry.
3. **Write-ups and lists** inside each folder: full write-ups, outlines, and lists of public links.

## How to read the labels

Every index uses the same five labels:

| Label | Values | Meaning |
|---|---|---|
| **Status** | live / outline / draft | *live*: public and checked to load, or a finished write-up. *outline*: a structured summary still to be written in full. *draft*: written but not public. |
| **Evidence** | documented / by my account | *documented*: a dated record exists. *by my account*: my own description, with no record attached. |
| **Type** | pipeline / governance / writing / community / promo | The kind of work. |
| **Dates** | a date or a range | When the work happened, in US Eastern time. |
| **Quality notes** | short text | Only what the records support: tests, audits, fixes, read-backs. Blank when there is no record. |

## Ground rules

- Every number comes from a dated record. Links were checked on Nov 10, 2026.
- Names of other people, account handles and private sources are left out on purpose.
- No credentials, private files or drafts are linked.
