# How to add a workflow

1. Copy `TEMPLATE.md` into the right section folder, or into `workflows/` if it fits no section. Name it in lowercase with dashes, for example `weekly-report-loop.md`.
2. Fill in every heading. Write "Not measured yet" rather than leaving a heading empty.
3. Label it: Status, Evidence, Type, Dates and Quality notes, as defined in the root README.
4. Add a row for it to that folder's `README.md`, and update the entry count in the root README map.
5. Check every link loads, and remove any that do not.
6. Run the leak check (the word list is in the privacy checklist) before saving.
